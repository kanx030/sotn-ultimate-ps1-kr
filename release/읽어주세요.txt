원본 이미지 만드는 법
--------------------
이 패치의 원본 "SOTN Ultimate (PS1 Version) v1.4.bin"은 팬 개조판 제작 페이지(builder.html)로
직접 만듭니다. 세 가지 게임 디스크 이미지가 필요합니다.

  1. PS1 북미판 - Castlevania: Symphony of the Night (SLUS-00067)

  3. PSP 북미판 - Castlevania: The Dracula X Chronicles (ULUS-10277)

만드는 순서
  1. 반드시 v1.4판 제작 페이지를 받습니다 (다른 판으로 만든 이미지에는 이 패치가 맞지 않습니다).
     https://github.com/renanbianchi/sotn-ultimate/releases/tag/v1.4  ->  builder.html
  2. builder.html을 PC의 크롬/엣지/파이어폭스로 열고, 위 세 이미지를 끌어다 놓습니다.
  3. "Build the disc"를 누르고 기다린 뒤 .bin과 .cue를 저장합니다.
  4. 결과 MD5가 901d74656aedbd8da3050d6a3716f32f 이면 이 한글 패치를 적용할 수 있습니다.

적용 방법
---------
1. xdelta 패치 프로그램을 준비합니다. (예: Delta Patcher, xdelta UI, xdelta3)
2. 원본 파일: SOTN Ultimate (PS1 Version) v1.4.bin
   패치 파일: SOTN_Ultimate_KR.xdelta
3. 결과 파일 이름을 SOTN_Ultimate_KR.bin 으로 저장합니다.
4. 함께 든 SOTN_Ultimate_KR.cue 를 같은 폴더에 두고, cue 파일로 실행합니다.
   결과 CRC32  : d605e918
   결과 MD5    : 8f6c01eb45b9f14f84bddff4b86e7aa5
   결과 SHA-1  : eaf39e7477034dd2eb7a7c90beed2b04cc1ee803
   결과 SHA-256: fa6012f2bf8d0940301c401aec3c640ed6c34a19fa9d3328c95a1e359007d260

명령줄 예:
  xdelta3 -d -s "SOTN Ultimate (PS1 Version) v1.4.bin" SOTN_Ultimate_KR.xdelta SOTN_Ultimate_KR.bin

---------
- 음성 설정(설정 > 추가 설정 > 음성)마다 따로 맞춘 대본

- 켤 때 코나미 영상을 건너뛰어 제목 화면이 빨리 뜹니다.
- 모든 한글은 갈무리 글꼴로 통일했습니다. (게임오버 문구만 함렛 글꼴)

치트
----
- 알카드: 일시정지 -> 설정 -> "치트"
  HP/MP/하트 무한, 무적, 골드 999999, 마도기 전부(신속의 신발 포함), 마법 전부,
  아이템 전부 9개, 장비 전부 9개, 능력치 99, 레벨 업
- 리히터·마리아: 일시정지 화면에서
  L1+R1 = HP 무한 켜기/끄기,  L2+R2 = 하트 무한 켜기/끄기
  (화면에 켬/끔이 표시됩니다. 일시정지 중에만 바꿀 수 있습니다.)


에뮬레이터 설정 (덕스테이션·안드로이드 포함)
------------------------------------------
- 반드시 패치 결과의 MD5가 위 "결과 MD5"와 같은지 먼저 확인하세요.
  (원본은 반드시 v1.4여야 합니다. 다른 판의 원본에는 맞지 않습니다)
- .bin 이름을 바꿨다면 .cue 안의 FILE 줄 이름도 똑같이 바꾸세요. 두 파일은 같은 폴더에 두고 .cue로 엽니다.
- 바이오스는 반드시 북미판 실제 PS1 바이오스 SCPH-1001을 쓰세요 (내장·대체 바이오스 사용 금지).
  (시험 결과: 북미 1001·7001·7003·PSone(101), 유럽 7502도 동작. 일본 5500·7000은 북미판 디스크를
   거부해 원본 얼티메이트도 켜지지 않습니다.)
- 빠른 부팅은 끄는 것이 가장 안전합니다.
- CD 읽기·탐색 가속은 끄기(1배속), 8MB 램 끄기, 치트 끄기.
- 압축(CHD)으로 바꿀 때는 .cue에서 변환하세요.
- 다른 판이나 영문판에서 만든 "상태 저장"은 쓰지 마세요 (메모리 카드 저장은 됨).
- 덕스테이션 데스크톱판(안드로이드판과 같은 핵심)에서 .cue/.bin/CHD, 빠른 부팅 켬/끔 모두 동작을 확인했습니다.
