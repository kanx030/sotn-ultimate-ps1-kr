# DuckStation 실행 확인 (2026-11-13)

안드로이드 DuckStation에서 "한글 패치가 안 돈다"는 제보를 받고, PC용 DuckStation(같은 코어)으로 배포판 결과물을 여러 조건에서 켜 봤습니다.

## 결론
- **우리 패치 결과물(rel14b, 배포 ult-v1.4와 같은 MD5 `07c2f2090a9db3cf002dc0ec58c052e7`)은 DuckStation에서 모든 조건에서 정상 실행됩니다.** 원본 v1.4와 다른 점이 없었고, 기록(로그)에 CD 읽기 오류·섹터 오류·지역 경고(우리 탓)가 하나도 없었습니다.
- 그래서 빌드 도구는 고치지 않았고 새 이미지(rel14c)도 만들지 않았습니다.
- 실패를 다시 만들 수 있었던 경우는 **cue 파일 안의 파일 이름과 실제 bin 이름이 다를 때**뿐입니다 (사용자 실수, 아래 참고).

## 시험 환경
- DuckStation 0.1-12640 (2026-11-07판) Windows. 사용자 설치본은 건드리지 않고 `test/duckstation_copy`에 프로그램만 복사해 휴대 모드(portable.txt)로 실행, 설정·메모리 카드·기록 모두 복사본 안에만 둠.
- 바이오스: SCPH-1001(북미, v2.2), SCPH-5500(일본, v3.0)
- 설정: 소프트웨어 기본값, 8MB 램 끔, CD 읽기·탐색 가속 1배, 기록 수준 Dev(CD 명령 하나하나 기록)
- 도구: `tools/ds/dsrun.py`(켜고 10초마다 화면 갈무리), `tools/ds/ctl.py`(켜기·키 입력·갈무리·끄기, 우리 PID만 종료), `tools/ds/base.ini`
- 결과 화면·기록: `test/ds/out/` (깃에는 없음)

## 의심했던 것과 확인 내용
- **이미지 끝에 붙인 일본어 낭독 구간 (LBA 299644부터 16,328섹터)**: ISO 볼륨 크기(PVD)는 원본 그대로 299,644이고 이미지는 315,972섹터. DuckStation은 cue/bin과 CHD 모두 트랙 길이를 파일 크기로 잡음 (chdman도 "Input length 70:12:72" = 315,972섹터로 전부 담음). 볼륨 크기는 PS1과 에뮬레이터 모두 보지 않음. 붙인 섹터의 머리(MSF)는 새 위치로 바르게 고쳐져 있음(예: LBA 299644 = 66:37:19). 폼2 섹터의 EDC는 머리를 포함하지 않고, 모드2의 ECC는 머리 주소를 0으로 놓고 계산하므로 주소를 바꿔도 오류 검사에 걸리지 않음. DuckStation은 읽을 때 EDC/ECC를 검사하지도 않음.
- **실행 파일 시작 주소(pc0)를 바꾼 것 + 빠른 부팅**: 빠른 부팅은 바이오스 로고만 건너뛰고 SYSTEM.CNF의 실행 파일을 그대로 바이오스로 불러오므로 우리 시작 코드(글꼴·치트 복사)가 그대로 돎. 켬/끔 모두 한글 제목·메뉴 확인.
- **XA 스트리밍 시점**: 오프닝 영상(STR)·음악 XA 정상 재생. 낭독 구간 자체는 드라큘라전 뒤 자막 장면이라 이번에 DuckStation에서 직접 듣지는 못함 (RetroArch에서는 확인됨). 읽는 방식이 같은 파일 읽기라 위험 낮음.
- **xdelta 형식**: 배포 패치는 `-S djw`(2차 압축)로 만듦. 원본 xdelta3, Delta Patcher, 최신 ROM Patcher JS 모두 djw를 지원하므로 원인으로 보지 않음. 단, 오래된 패치 앱이나 휴대폰 브라우저 메모리 부족(700MB 파일)으로 결과가 잘못 만들어질 수는 있음 → 결과 MD5 확인을 안내.

## 안드로이드 사용자 안내 (원인 후보 = 사용자 쪽)
1. **결과 MD5 확인**: `07c2f2090a9db3cf002dc0ec58c052e7` (743,166,144바이트)가 아니면 패치가 잘못된 것. 가장 흔한 원인은 **원본이 v1.4가 아님** (v1.2 원본용 배포는 2026-11-14 종료) 또는 원본 MD5 `901d7465…` 불일치.
2. **cue와 bin 이름을 맞출 것**: 함께 든 `SOTN_Ultimate_KR.cue`는 `SOTN_Ultimate_KR.bin`을 가리킴. bin 이름을 바꿨다면 cue 안 FILE 줄도 똑같이 고치거나, cue 없이 bin을 바로 열어도 됨. cue와 bin은 같은 폴더에, 그 폴더를 DuckStation 게임 폴더로 추가.
3. **진짜 바이오스 사용** (북미 SCPH-1001 권장, 일본 바이오스도 동작), 빠른 부팅은 끄는 것이 원작자 권장이지만 켜도 동작함.
4. **CD 읽기·탐색 가속(Read/Seek Speedup)은 1배(없음)**, 8MB 램 끔, 치트·게임 패치 끔.
5. **예전 상태 저장(세이브 스테이트) 쓰지 말 것**: 다른 판·영문판 상태를 불러오면 멈춤. 메모리 카드 저장은 됨.
6. CHD로 바꿔도 됨 (chdman createcd로 만든 CHD 확인함). 단 cue를 넣어 바꿀 것.
7. 그래도 안 되면 DuckStation 판 번호와 화면(검은 화면/오류 문구)을 받아 볼 것.
