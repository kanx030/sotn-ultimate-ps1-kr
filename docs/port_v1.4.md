# SOTN Ultimate v1.4 이식 기록

원본을 v1.2 → v1.4로 바꾼 작업 기록. (진행 중 메모를 겸함)

## 바뀐 것 (원작자 변경 노트 `docs/upstream_notes_v1.3_v1.4.txt` + 파일 비교)
- DRA.BIN: 크기는 같고 코드·문자열 위치가 군데군데 밀림 (메뉴 그리기 -0x74, 문자열 +0x60, 하트/체력 표시 등). 아이템 이름 2개 대소문자만 바뀜 (Glaring cloth, Rainbow mantle) → 한글 이름 그대로.
- SEL/SELRIC2: 0x2F4F0~0x2F54C 사이에 16바이트가 들어가 그 뒤 전부 +0x10 (음성별 엔딩 대본, 사운드 모드 표, 부팅 로고 코드, 고딕 글자 그리는 곳).
- ST0: 0x280CC 뒤 +4, 0x2AEFC 뒤 +0x2C (자막 글자 함수, 자막 대본 포인터 BSS도 +0x2C). 대사 대본 위치는 그대로.
- LIB: 0x38634 뒤 +0x34 (이름표 루프). 대본·상점·적 설명 위치는 그대로.
- DAI, NO3: 대본 위치 그대로 (NO3는 뒤쪽 데이터만 크게 밀림). NO3RIDE.BIN(말 타기 새 파일)·바뀐 오버레이에 새 영어 문장 없음 (`work/U` 대 `work/U14` 문자열 비교).
- XA_STR1 위치 51894 → 52588 (일본어 낭독 항목의 오프셋 계산에 반영).
- ARC_F2(추가 설정 메뉴)는 같은 자리, 11바이트만 다름 → 그대로 맞음.

## 주소 찾는 방법 (다음 버전도 같은 방식)
- `tools/base.py`: 원본 판 선택 한 곳. 기본 v1.4, `SOTN_BASE=1.2`로 옛 판. 각 판 = `원본롬/` 이미지 + `work/U`(1.2) / `work/U14`(1.4) 추출본 (`python extract_base.py 1.4`). `work/bases.json`(ultimate_update.py가 기록)에 있는 판도 자동 등록.
- `tools/addrmap.py`: 옛 판(v1.2) 파일과 지금 판 파일에서 한 번씩만 나오는 16바이트 묶음을 맞춰 구간별 이동량 지도를 만듦.
  - `addrmap.dra(v12주소)`, `addrmap.ovl(파일, v12주소)`: v1.2 주소에 있던 바이트(점프 대상·즉치값·포인터는 가린 서명)를 지금 판에서 찾아 새 주소를 돌려줌. 못 찾거나 여러 곳이면 멈춤.
  - `addrmap.ovl_var(파일, v12주소)`: 파일 밖 변수(BSS)는 그 변수를 쓰는 lui/lo 명령 쌍을 옮겨진 코드에서 다시 읽어 찾음 (모두 같은 값이어야 통과).
  - `addrmap.port_code(바이트)`: v1.2 코드 조각 안 jal 대상을 지금 판 주소로 바꿔 원본 확인용으로 씀.
  - `addrmap.remap_runs(파일, 표)`: (v1.2 위치, 원문, 한글) 표를 원문 바이트로 지금 판 위치에 맞춤 (seltext 등).
- 도구 코드(*.py)의 주소는 계속 v1.2 값으로 적고 `_R(...)`/`addrmap.ovl(...)`로 감쌈 → 빌드 때 지금 판 주소로 바뀜. 그래서 v1.2 추출본(`work/U`)이 계속 있어야 함.
- 번역 시트(`work/trans/*.json`)는 지금 판 위치로 다시 맞춤: `python rekey.py 1.2 1.4 --write` (각 항목 원문 바이트로 새 위치 확인, 바뀐 것만 저장). DRA_A/DRA_B는 표에서 다시 뽑아 같은 id의 한글을 유지 (`drab.cmd_extract`, draa 재키).
- 서명으로 찾게 바꾼 곳: 오버레이 하단 이름 띠(BottomCornerText), 대사 엔진·이름 루프(원래부터 서명), 일본어 낭독 조회 코드(주소 부분만 가리고 비교, 대체 항목·점프 대상은 원본 코드에서 읽음).
- v1.2로 다시 만들기: 시트가 v1.4 위치라 `git checkout v1.2-base-final` (태그) 에서 빌드.

## 확인한 것
- 빌드: 시험판 `work/build/p14a.bin`(--test), 배포판 `work/build/rel14a.bin` (MD5 `07c2f2090a9db3cf002dc0ec58c052e7`, 743,166,144바이트). 빌드 로그(번역 줄 수, SELRIC2, g7 여유)가 v1.2 마지막 빌드(testC16)와 똑같음.
- `scriptcheck.py`: 두 빌드 모두 19개 오버레이 대본 불일치 0.
- 바뀐 오버레이 영어 검사: v1.2 대 v1.4 원본 문자열 비교에서 새 영어 문장 없음 (NO3RIDE.BIN 포함, 나온 건 그림 데이터 조각뿐).
- 에뮬레이터 (test/port14/ 스크린샷):
  - 제목 한글(코나미 영상 건너뜀, 배포판도), 메인 메뉴, 사운드 모드(옮겨진 표), 파일 선택, 캐릭터 선택·추가 옵션
  - 프롤로그 대사 PSP / PS1 / 일본어 세 음성 모두 한글, 오프닝 자막 한글 + 일본어 음성 낭독 스트림 재생 확인 (XA 기준 52588, file 0x1E/ch6, 붙인 LBA 299644+6)
  - 불러오는 중 화면, 알카드 상태·장비·아이템 설명(맨손, 포션)·설정(치트 창, 추가 설정), 치트(레벨 업, 아이템)
  - 게임오버 문구 "영원한 안식" + 자막, 게임오버 후 한글 제목
  - 리히터 새 게임: 말 타기(NO3RIDE) → 일시정지 치트 L1+R1 / L2+R2 표시·동작, 마리아도 같음
  - 장서관(LIB): 도서관 카드로 이동 → 사서 첫 만남 대사 한글(이름표 알카드/사서), 상점·적 목록 한글
  - 악몽(DRE) 리사 대사 한글, 왕실 예배당(DAI) 지역 이름 한글 (RAM 순간이동: D_8006C374 = 순간이동 번호, g_GameStep 0x80073060 = 4; v1.4 순간이동 표는 DRA 0x800A21C8, 10바이트씩)

## 남은 것 / 메모
- NO3 데스 장면: 새 게임에서 성 입구를 걸어도 데스가 안 나옴(강탈 플래그 0x8003BDEC+0x35 그대로 0). 원본 v1.4 NO3 코드를 RAM에 되돌려 넣어도 똑같아서 한글 패치 탓은 아님 (진행 조건 미확인, 우리 시험 방식 문제일 수 있음). NO3 대본은 정적 검사만 통과.
- DAI 대사 장면(마리아)은 실기로 못 봄: 순간이동으로는 방 그림이 깨져 마리아 방을 못 찾음. 대본 위치가 v1.2와 같고 scriptcheck 0, 훅도 같은 서명이라 위험은 낮음.
- 알아둘 것: Ultimate의 g_Status는 소스(디컴프) 주석보다 0x14 뒤 (HP 0x80097BB4, 최대 HP 0x80097BB8, 하트 0x80097BBC, 장비[0] 0x80097C14).
- README·배포용 읽어주세요 문서는 아직 v1.2 기준 (배포할 때 원본 MD5·제작 페이지 v1.4로 고칠 것).
- v1.2로 다시 만들려면 `git checkout v1.2-base-final` 후 빌드 (시트 위치가 v1.4 기준이라 지금 코드로는 안 됨).
