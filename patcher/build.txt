월하의 야상곡 얼티메이트 한글 패처 — 소스와 빌드 방법
====================================================

라이선스: GNU 일반 공중 사용 허가서 2판 또는 그 이후 판 (GPL-2.0-or-later). 전문은 GPL-2.0.txt.

■ 파일
  sotn_core.py      핵심 처리 (이미지 찾기, 판 판별, xdelta 패치, CHD 풀기·만들기, 그 자리 업데이트)
  sotn_patcher.py   화면 (tkinter). 시험용 창 없는 실행:
                    --cli <이미지 또는 폴더> <저장폴더> <이름> <bincue|chd> <new|replace> <기록파일>
  아이콘·로고는 원작 화면을 바탕으로 만든 것이라 이 공개본에 넣지 않았습니다.
    빌드할 때 icon.ico, logo.png, logo_15.png, logo_2.png(로고 높이 76/114/152 픽셀)를
    직접 만들어 이 폴더에 두세요. 로고가 없으면 화면에 제목 글자만 나오고 패처는 그대로 돕니다.
  GPL-2.0.txt       라이선스 전문

■ 빌드에 필요한 것
  Python 3.13 (tkinter 포함), PyInstaller 6.22 이상
    python -m pip install pyinstaller

■ 빌드 (이 폴더에서)
  python -m PyInstaller --noconfirm --clean --onefile --noconsole --name sotn_kr_patcher ^
    --icon icon.ico --add-data "icon.ico;." --add-data "logo.png;." ^
    --add-data "logo_15.png;." --add-data "logo_2.png;." sotn_patcher.py
  → dist\sotn_kr_patcher.exe 를 "월하_한글패처.exe" 로 이름을 바꿔 배포 폴더에 둡니다.

■ 배포 폴더 구성 (exe 옆)
  월하_한글패처.exe
  patch\versions.json        지원하는 판(원본·예전 한글판)과 패치 목록, 최신 판 해시와 CHD SHA1
  patch\*.xdelta             패치 파일 (원본→최신, 예전 한글판→최신)
  tools\xdelta.exe           xdelta 3.1.0  https://github.com/jmacd/xdelta (태그 v3.1.0)
  tools\chdman.exe           MAME 0.215 chdman  https://github.com/mamedev/mame (태그 mame0215)
  tools\chdman.dll           RomForge v2.0.4 의 chdman 래퍼 (RomForge_Dlls.zip, SHA-256 565BD4DC…E9B661)
                             https://github.com/sinjunyoung/RomForge — 한글 경로를 그대로 처리.
                             없거나 실패하면 영문 임시 폴더 + tools\chdman.exe 로 자동으로 대신함
  라이선스.txt, GPL-2.0.txt, 사용법.txt
